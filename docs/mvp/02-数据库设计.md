# MVP 数据库设计

迁移：`20261110124235_init`、`20261110224824_lead_conversion`、`20261110225252_lead_conversion_trigger_fix`、`20261110230555_audit_logs`、`20261110231108_audit_logs_clock_timestamp`、`20261110232938_user_roles`（目录 `prisma/migrations/`）。Schema：`prisma/schema.prisma`。

## 约定
- UUID 主键；时间 `timestamptz(6)`（UTC）；金额 `numeric(18,2)` + `currency char(3)`（默认 CNY）。
- 所有业务表含 `organization_id`，值只来自服务端会话。
- 业务表都有 `UNIQUE (organization_id, id)`，所有引用（负责人、客户、线索、商机）使用 **复合外键 `(organization_id, xxx_id)`**，数据库层面禁止跨组织引用。
- 常用查询索引：`(organization_id, created_at desc)`，以及按状态/阶段/关联 ID 的组合索引。

## 表
| 表 | 说明 | 关键字段 / 约束 |
|---|---|---|
| organizations | 组织（租户） | name |
| users | 用户 | email 全局唯一（登录用）、password_hash(Argon2id)、role(user_role：ADMIN/MANAGER/SALES/READONLY)、is_active、is_demo（演示账号） |
| sessions | 会话 | token_hash（SHA-256，唯一）、expires_at |
| leads | 线索 | name、company、title、phone、mobile、email、source、status(lead_status)、owner_id；转化结果 converted_account_id / converted_contact_id / converted_deal_id（删除时置空，同组织由触发器 `leads_conversion_same_org` 保证）、converted_at（CHECK：状态为 CONVERTED 当且仅当 converted_at 非空） |
| accounts | 客户 | name、industry、phone、website、address、owner_id |
| contacts | 联系人 | account_id（删除客户级联删除）、name、title、phone、email、is_primary |
| deals | 商机 | account_id（有商机的客户禁止删除，RESTRICT）、amount ≥ 0（CHECK）、currency、stage(deal_stage)、expected_close_date(date) |
| audit_logs | 审计日志（只追加） | organization_id、actor_id（复合外键到 users）、action、entity_type、entity_id（无外键，记录删除后保留）、changes(jsonb，已脱敏)、ip、user_agent、created_at(clock_timestamp)；触发器禁止 UPDATE/DELETE |
| activities | 跟进/任务 | type(CALL/MEETING/VISIT/TASK)、subject、content、due_at、completed、completed_at（CHECK 一致性）、account_id/lead_id/deal_id（关联删除时级联） |

## 枚举
- lead_status：NEW, CONTACTED, QUALIFIED, UNQUALIFIED, CONVERTED
- deal_stage：QUALIFICATION, NEEDS_ANALYSIS, PROPOSAL, NEGOTIATION, CLOSED_WON, CLOSED_LOST
- activity_type：CALL, MEETING, VISIT, TASK
