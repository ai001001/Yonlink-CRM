## 后端公网部署待决事项
GitHub Pages 前端需通过 HTTPS 调用 Oracle 服务器上的 API。需要负责人提供或批准：
1. 域名（或子域名）及 DNS 解析到服务器公网 IP；
2. OCI 安全列表与系统防火墙放行 443（需 sudo）；
3. 反向代理与证书（如 Nginx + Let's Encrypt，需 sudo）；
4. 生产/演示环境独立数据库与 `.env`（`CORS_ORIGINS=https://ai001001.github.io`）。
完成后将 Pages workflow 中 `NEXT_PUBLIC_STATIC_PREVIEW` 改为 `0` 并设置 `NEXT_PUBLIC_API_BASE`。
