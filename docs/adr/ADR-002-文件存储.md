# ADR-002 文件存储：本地磁盘 + 统一存储接口

- 状态：提议中
- 日期：2026-11-08
- 取代：`docs/03-系统架构.md` 中 “S3 兼容存储 / MinIO” 的第一阶段落地方式
- 关联：ADR-001、ADR-005、ADR-007、ADR-008

## 1. 背景
- 原蓝图使用 MinIO。经核查，Docker Hub `minio/minio` 已返回 404，社区版镜像不再发布。
- 负责人约束：第一阶段优先本地磁盘；不得以 AWS S3、阿里云 OSS、腾讯云 COS 等付费云存储为运行前提；后续仅可扩展为**本机自托管** S3 兼容服务。
- 第一阶段业务上传量很小（无附件模块），但存储抽象必须先定型，避免后续返工。

## 2. 决策

### 2.1 统一接口（`packages/` 内定义，业务模块只依赖接口）
```ts
/** 存储提供者 / Storage provider */
interface StorageProvider {
  put(key: StorageKey, body: Readable, meta: PutMeta): Promise<StoredObject>; // 返回 size、sha256
  getStream(key: StorageKey): Promise<Readable>;
  stat(key: StorageKey): Promise<StoredObject | null>;
  delete(key: StorageKey): Promise<void>;
}
```
- 第一阶段实现：`LocalDiskStorageProvider`。
- 预留实现：`S3CompatibleStorageProvider`，仅用于本机自托管服务（如 SeaweedFS、Garage、RustFS），启用前需新 ADR 评估资源占用。
- 选择由配置 `STORAGE_DRIVER=local` 决定；业务代码不得直接访问文件系统路径。

### 2.2 存储键与目录
- 根目录：`/home/ai/yonlink-data/<env>/files`，以只读以外的最小权限挂载进 `api`、`worker` 容器。
- 键格式（服务端生成，**绝不使用用户提交的文件名或路径**）：
  `t/{tenant_id}/{category}/{yyyy}/{mm}/{uuidv7}`
- `tenant_id` 来自服务端租户上下文（ADR-005），不可由客户端指定。
- 原始文件名、MIME、大小、sha256 存数据库元数据表（附件模块进入时建表；第一阶段不建空表）。
- 目录权限 `0750`、文件 `0640`，属主为容器内非 root 运行用户。

### 2.3 写入与读取
- 写入：先写同目录临时文件 → `fsync` → 原子 `rename`；边写边计算 sha256 与大小。
- 校验：单文件大小上限（默认 20 MB，可配）、MIME 魔数嗅探与扩展名白名单、拒绝路径分隔符与 `..`。
- 下载：必须经 API 鉴权（租户 + 记录权限）后流式返回，或由 API 鉴权后返回 `X-Accel-Redirect` 交由 Nginx `internal` location 发送；Nginx **不得**直接公开文件目录。
- 响应头：`Content-Disposition: attachment`（默认）、`X-Content-Type-Options: nosniff`，防止上传内容被当作页面执行。

### 2.4 容量控制（与 ADR-007 联动）
- 第一阶段文件总预算 10 GB；租户级配额字段预留，默认 2 GB/租户（可配）。
- 磁盘使用率 ≥ 90% 时 API 拒绝新上传（HTTP 507 + i18n 错误码），不影响读取。
- 删除采用“元数据软删除 + 保留期后物理清理”，清理任务由 Worker 执行并写审计。

### 2.5 备份
- 文件目录由 restic 增量备份（ADR-008）；sha256 用于恢复后校验。

## 3. 备选方案
| 方案 | 结论 | 原因 |
|---|---|---|
| MinIO | 否决 | 镜像不可得；自编译为 AGPL 且项目处于维护模式 |
| 本机 SeaweedFS / Garage / RustFS | 推迟 | 额外 200–500 MB 内存；第一阶段无必要；接口已预留 |
| 云对象存储（S3/OSS/COS） | 否决 | 违反约束 |
| 数据库 BYTEA 存文件 | 否决 | 膨胀数据库与备份，影响 PostgreSQL 内存 |

## 4. 影响
- 单机磁盘为唯一在线副本；依赖 ADR-008 的离线备份保障。
- 切换到自托管 S3 时只需新增 Provider 与迁移脚本，业务代码不变。

## 5. 验收
- 单元测试：键生成拒绝 `..`、绝对路径、跨租户前缀。
- 集成测试：Tenant A 无法通过篡改 ID 下载 Tenant B 文件（404）。
- 原子写入测试：中途失败不留下半文件。
- 磁盘阈值模拟测试：≥ 90% 时上传被拒绝。
