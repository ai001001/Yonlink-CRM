# 永联CRM（Yonlink-CRM）架构决策记录（ADR）索引

本目录记录影响数据库主键、租户隔离、权限模型、模块边界、API 兼容性、货币精度、部署与基础设施的架构决策。
任何新增或变更都必须新增/修订 ADR，并经项目负责人批准后方可实施。

## 状态说明
- **提议中**：已起草，等待项目负责人审核。
- **已决策（待最终批准）**：负责人已在逐项决策中确定，待 T0-A 最终决策清单统一批准后转为“已批准”。
- **已批准**：负责人确认，可据此实施。
- **已取代**：被后续 ADR 替换，保留历史。

## 全局强制约束（2026-11-08 负责人指定，适用于所有 ADR）
1. 唯一服务器：现有 Oracle Cloud ARM64 Ubuntu 26.04（2 OCPU / 12 GB RAM / 100 GB 磁盘 / aarch64 / 用户 `ai` / 项目目录 `/home/ai/Desktop/CRM/Yonlink-CRM/`）。
2. 禁止以购买、租用或依赖其他云服务器、云数据库、云缓存、云对象存储、付费 CDN、付费 CI/CD 作为方案或运行前提。
3. PostgreSQL、Valkey、Next.js、NestJS、Nginx、Worker 全部部署在该服务器；Docker Compose + 模块化单体；不使用 Kubernetes，不拆分微服务集群。
4. 第一阶段文件存储使用本地磁盘，经统一存储接口访问；后续仅可扩展到本机自托管 S3 兼容服务。
5. 备份必须有容量告警、保留周期和离线（脱离本服务器）副本；同盘备份不得视为唯一灾备。
6. 所有服务必须遵守明确的内存、CPU、磁盘预算、日志轮转与容量监控。
