# 永联CRM（Yonlink-CRM）产品命名规范

## 正式名称
- 中文产品名称：永联CRM
- 英文产品标记：Yonlink-CRM
- 技术项目标识（slug）：`yonlink-crm`

## 统一规则
1. 中文界面、中文需求文档和中文介绍统一使用“永联CRM”。
2. 英文界面、英文文档和英文产品标记统一使用“Yonlink-CRM”。
3. 仓库目录、Docker Compose 项目名、包名及技术标识优先使用小写 `yonlink-crm`。
4. 不得再把旧项目名作为产品名称、默认目录名、页面标题或部署标识。
5. Zoho CRM 仅作为公开功能对标对象；永联CRM使用自主实现的代码、品牌和界面，不暗示与 Zoho 存在官方关联。

## Claude Code 强制要求
新增或修改代码、文档、测试数据、界面标题、部署配置时必须遵守本规范。提交前搜索旧项目名并清理非必要残留。
