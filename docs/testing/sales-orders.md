# 销售订单 — 三轮测试记录

日期：2026-11-14　环境：同 [leads.md](leads.md)　参考：Zoho CRM Sales Orders
迁移：`20261114120000_sales_orders`（新表 `sales_orders`、`sales_order_line_items`，枚举 `sales_order_status`；部分唯一索引：同一报价单只能有一张未取消的订单；CHECK：总计 = 小计 + 税额、税率 0–100、已发货/已交付必须有发货时间、交付与取消时间和状态一致、明细数量与金额合法；订单对报价单、商机的外键为 RESTRICT）

## 功能
- 生成：在报价单详情中，已接受且没有未取消订单的报价单显示“生成销售订单”。
  - 主题默认为报价单主题，收货地址默认为客户地址，可填预计交付日期与备注。
  - 明细、币种、税率与金额复制自报价单，生成后不再变化（后续修改产品或商机明细不影响订单）。
  - 订单号按组织、按年连续编号（SO-2026-0001），并发生成时用事务级咨询锁保证不重号。
- 状态：已确认 → 已发货 → 已交付；已确认、已发货可取消（可填取消原因）。已交付、已取消为终态，不能再修改。
  - 发货、交付、取消分别记录时间；并发流转只成功一次（条件更新）。
  - 订单取消后，报价单可以重新生成订单。
- 修改：未结束的订单可改主题、预计交付日期、收货地址、备注。
- 页面：
  - 左侧导航“销售订单”：按状态筛选，按订单号、主题、报价单号、商机、客户搜索。
  - 订单详情抽屉；打印页 `/print/sales-order?id=…`（浏览器打印或另存为 PDF）。
  - 报价单详情列出由它生成的订单（含状态），点击跳转。
- 订单不能删除，只能取消；有订单（包括已取消订单）的商机不能删除，提示“该商机已有销售订单，不能删除”；报价单被订单引用时数据库拒绝删除。
- 权限：可见与编辑跟随所属商机（销售代表只能操作自己负责商机的订单，只读用户只能查看）。
- 审计：生成（`order.create`）、修改（`order.update`）、状态变更（`order.status`）；收货地址、备注、取消原因按长文本脱敏；审计日志可按“销售订单”筛选。
- 中英文文案；演示数据：每张已接受的报价单生成一张订单，共 7 张（已交付 4、已发货 1、已确认 1、已取消 1）。
- 不做：发票、库存扣减、部分发货 / 发货单、订单生成后自动把商机改为赢单、订单金额修改。

### 失败与修复
| 现象 | 原因 | 修复 |
|---|---|---|
| R2 有 3 处 lint 警告 | 测试中解构出未使用的变量 | 改为直接覆盖字段，测试逻辑不变 |
| 演示订单初版没有“已确认”状态 | 按天数划分状态，而最新订单也已生成 11 天 | 改为最新一张已确认、次新一张已发货、其余已交付，便于演示发货操作 |
| 订单 E2E 首次 1 项失败 | 测试选择器问题：“已取消”同时出现在状态筛选和表格标签中 | 限定在状态筛选控件内点击 |
| R3 首次：既有“商机附件”E2E 超时（[首次失败输出](results/sales-orders-r3-regression-first-run-failed.txt)；其余 43/44 通过，Vitest 786/786） | 既有测试的时序问题：上传成功与类型错误的提示条盖住了商机详情的“关闭”按钮，鼠标悬停在提示条上会暂停其自动消失，点击一直被挡住；机器负载较低时提示条先消失所以以前未暴露 | 新增 E2E 辅助函数 `closeDrawer`：先等提示条全部消失再点关闭；附件 E2E 改用它；单独运行附件 E2E 2/2 通过后完整重跑第三轮 |
| R3 第二次：既有“分配通知”E2E 超时（[第二次失败输出](results/sales-orders-r3-regression-second-run-failed.txt)；其余 43/44 通过，Vitest 786/786） | 上一功能引入的竞态：铃铛“页面路径变化就收起弹层”的逻辑，会把导航尚未完成时打开的弹层立刻关掉（测试点菜单后 0.1 秒点铃铛；用户快速操作也会遇到）。该逻辑当初为修复“查看全部后弹层未收起”而加，实际那次只是关闭动画未结束 | 去掉路径变化收起弹层的逻辑（点通知、点“查看全部”时本来就会收起）；E2E 等导航完成再打开铃铛，并保留“跳转后弹层已收起”的断言；单独运行通知与附件 E2E 4/4 通过后完整重跑第三轮 |
