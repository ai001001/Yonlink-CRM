## 功能
- **员工侧**（`portal.manage`：管理员、经理）：
  - 设置 › 客户门户：启用/关闭、欢迎语、门户登录地址（首次启用时生成随机门户标识）与门户用户数量。关闭后所有客户的会话立即失效（每个请求都检查）。
  - 联系人详情的“客户门户”区：开通门户（联系人须有邮箱）→ 显示一次性邀请链接（7 天有效，只显示一次；数据库只存哈希，审计不记录令牌）；已开通的再次邀请即重设密码链接；停用会清除邀请并结束其全部会话。
  - 工单评论中显示客户在门户中的回复（“客户 姓名”）；员工不能编辑客户回复，有删除权限的员工可以删除。
- **客户侧**（`/portal/…`，独立于员工登录）：
  - 接受邀请设置密码（至少 10 位）后自动登录；之后用门户登录地址、邮箱、密码登录。
  - 认证：Argon2id 密码；会话令牌以 `ylp_` 开头、数据库只存 SHA-256、12 小时有效；同一门户同一邮箱 15 分钟内最多 10 次失败；邮箱不存在时也做一次哈希校验。员工令牌与 API 密钥不能访问门户接口，门户令牌不能访问员工接口。
  - 每个请求都校验会话、门户用户状态、组织门户是否启用、联系人是否仍存在；组织、联系人、所属客户只来自会话（联系人换客户后立即按新客户显示）。
  - 我的工单：只看自己作为联系人的工单（最多显示最近 200 条）；提交新工单（渠道“客户门户”、负责人为客户负责人、按 SLA 计算期限、通知负责人）；工单详情只显示公开评论（内部备注不显示）；回复后已解决或等待客户的工单重新打开，已关闭的工单不能回复；回复通知负责人。
  - 报价单（已发送、已接受、已拒绝）与发票（不含作废，显示已付与未付）：所属客户的全部报价单与发票，只读。
  - 修改密码（其他会话失效）、退出。
- **审计**：门户设置、开通/重设、停用、客户接受邀请、登录与登录失败、修改密码；客户新建工单与回复记为“来自客户门户（联系人）”，没有员工操作人。
- **演示数据**：演示组织的客户门户已启用（门户标识由组织 ID 推导，重建后地址不变）并有欢迎语；不预置门户账号与密码，演示时在联系人详情中开通、用邀请链接设置密码。
- **其他修正**：补上区域“重新分配”、销售节奏“加入/停止”、流程蓝图“流程推进”等审计操作的中英文名称（原先在审计日志中显示英文代码）；销售节奏列表的参与数量列标题改为“参与情况”。
- **已知限制**：登录失败限流与员工登录相同，保存在服务进程内存中，服务重启后清零、多进程部署时不共享；当前演示环境为单进程。若改为多进程，需要把限流移到数据库或 Valkey。
- **不做**：通过邮件发送邀请与通知（邮件集成最后做）、客户自助找回密码（由员工重新发送链接）、门户中的知识库（现有知识库没有“对外公开”标记，避免泄露内部文章）、报价单在线接受、发票在线支付、门户附件上传。

## 第一轮：功能测试
命令：`npx vitest run tests/portal/portal.r1-functional.test.ts`
结果：**5/5 通过**（首次运行 4/5，见下方“失败与修复”）。原始输出：[results/portal-r1-functional.txt](results/portal-r1-functional.txt)

覆盖：
- **设置**：生成标识格式；销售 403；经理可读取与修改；空白欢迎语视为清空；不能直接改标识；审计。
- **邀请与登录**：
  - 未开通为空；联系人没有邮箱 400；销售 403；开通后为待接受、邮箱转小写；审计中找不到令牌；数据库只存哈希。
  - 同邮箱的另一个联系人不能开通（409）；短密码 400；错误令牌 400；接受成功得到 `ylp_` 令牌；同一令牌再次使用 400；过期邀请 400。
  - 登录邮箱不区分大小写；错密码、未知邮箱、错误门户标识均 401；连续失败 10 次后 429。
  - 令牌隔离：门户令牌访问员工接口 401，员工令牌访问门户接口 401。
- **生命周期**：
  - 重设密码：接受前旧密码仍可用，接受后旧会话与旧密码失效。
  - 修改密码：当前密码错 400；成功后其他会话失效、当前会话保留。
  - 关闭门户：会话立即失效、不能登录、不能开通；重新启用后恢复。
  - 停用：会话全部删除、不能登录；再次邀请后恢复。退出后会话失效。删除联系人后门户用户随之删除、会话失效。
- **工单**：只看到自己的（同客户其他联系人、别家客户的都看不到，访问他人工单 404）；空主题 400；新建后渠道、负责人、联系人、类型正确，通知负责人，审计没有员工操作人；员工能在工单列表看到。
  - 内部备注不显示、员工回复显示姓名；回复已解决的工单后重新打开并清除解决时间，通知负责人；员工看到客户回复；再次回复不重新打开；已关闭 409；回复他人工单 404。
- **报价单与发票**：只看所属客户的，不含草稿与作废，未付金额正确；联系人换到别家客户后随之变化。

覆盖：
- **并发**：同一邀请被 3 个请求同时接受，只成功一个、只建一个会话，成功者的密码可登录；同邮箱的两个联系人同时开通，一个成功、一个 409。
- **会话过期**后 401。
- **数据库约束**：大写邮箱、已开通无密码、待接受无令牌、只有令牌没有期限、非法门户标识、跨组织联系人、评论同时有两个作者，均被拒绝。
- **评论**：员工不能编辑客户回复（403），经理可删除；删除门户用户后客户回复保留，作者置空、组织不变。
- **组织隔离**：同一邮箱在两个组织各自开通，各自只看到本组织的工单；用 A 的门户标识登录只能进入 A；关闭 B 的门户不影响 A；工单列表最多 200 条。
- **演示数据**：门户已启用、标识与欢迎语正确、没有预置门户账号；开通一个有工单的演示联系人后，看到其全部工单与所属客户的非草稿报价单。

|---|---|---|
