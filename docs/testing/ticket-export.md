# 工单导出 CSV — 三轮测试记录

日期：2026-11-16　环境：同 [leads.md](leads.md)　依赖：[服务工单](tickets.md)、[导入导出](import-export.md)
迁移：无

## 功能
- 服务工单页右上角新增“导出”按钮，按当前筛选导出 CSV：状态分组、优先级、负责人、只看逾期、搜索词，与列表完全一致。
- 列：工单号、主题、客户、联系人及其电话和邮箱、类型、来源渠道、优先级、状态、是否逾期（按导出时刻计算）、负责人、处理期限、解决时间、创建时间（时间为北京时间）、处理记录数、描述、解决方案。
- 格式：沿用现有导出。
  - 带 BOM 的 UTF-8，Excel 可以直接打开。
  - 多行文本和逗号会正确加引号。
  - 以 `= + - @` 等开头的内容前加单引号，防止公式注入。
  - 最新的工单在前。
  - 单次最多 10,000 条，超出时截断，并提示“只导出了前 N 条”。
  - 表头和枚举值随界面语言（中文 / 英文）变化。
- 权限：需要导出权限（管理员、经理）；销售和只读用户看不到按钮，直接调接口返回 403。导出的范围仍遵循可见范围。
- 审计：每次导出记录一条“服务工单 · 导出”，包括条数、是否截断、筛选条件、是否用了搜索。不记录搜索词。
- 不做：选择导出哪些列、导出处理记录正文、定时导出。

覆盖：
- 导出头：条数、截断标记、文件名。
- 18 列表头；各枚举值翻译成中文。
- 逾期判定：未解决的逾期工单为“是”，已解决的过期工单为“否”。
- 处理记录数；多行和含逗号的描述原样还原；公式开头内容加单引号；解决时间的格式。
- 筛选与列表一致：未解决、指定状态、优先级、逾期、搜索。
- 审计只记筛选，不记搜索词；英文表头与英文枚举值。
