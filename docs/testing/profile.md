# 个人设置与修改密码 — 三轮测试记录

日期：2026-11-15　环境：同 [leads.md](leads.md)　参考：Zoho CRM 个人设置（Personal Settings / Security）
迁移：无

## 功能
- 入口：右上角用户菜单“个人设置”（`/profile`；不在左侧导航中，打开时导航不高亮任何项）。
- 账号信息：显示名称（可修改，右上角同步更新）、登录邮箱、角色、组织、创建时间；修改名称写审计 `user.update`（标注来自个人设置）。
- 修改密码：
  - 须输入当前密码；新密码沿用用户密码规则（10–200 个字符）且不能与当前密码相同；前端校验两次输入一致。
  - 成功后其他设备上的登录全部失效，当前设备保持登录；审计 `user.change_password`（只记失效的会话数）。
  - 当前密码错误：返回“当前密码不正确”并写审计 `user.change_password_failed`；同一用户 15 分钟内错误 5 次后暂时锁定（429），不影响正常登录与其他用户。
  - 演示账号不能设置密码（403）：演示账号只能免密登录，若允许设置密码，任何访问者都能给公共演示账号设定密码。
- 登录设备：显示当前有效的登录及登录、到期时间，标出当前设备；“退出其他所有设备”（审计 `auth.logout_others`）。
- 最近登录记录：本人最近 20 条登录、演示登录、登录失败（含原因）、退出、退出其他设备，显示时间、IP、浏览器。
- 安全：密码与密码哈希不返回、不写入审计；会话只返回 ID 与时间，不返回令牌哈希；个人设置接口只接受名称与密码字段，不能借此修改角色、邮箱、组织或状态；登录记录只读取本人的。
- 新接口：`GET/PATCH /api/profile`、`POST /api/profile/password`、`POST /api/profile/sessions/revoke-others`。
- 不做：修改登录邮箱（需邮件验证）、两步验证、头像、按设备逐个退出。

### 失败与修复
| 现象 | 原因 | 修复 |
|---|---|---|
| 打开个人设置时左侧导航高亮“工作台”（开发中自查） | 导航高亮在找不到匹配项时默认回到工作台 | 不在导航中的页面不高亮任何项 |
| E2E 首次 1 项失败：新建专用账号失败 | 测试代码调用了只读的 `/api/users`，用户管理接口实际为 `/api/admin/users` | 改正路径（E2E 使用专用账号，不修改公共 E2E 管理员密码） |
