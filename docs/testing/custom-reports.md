## 功能
- **入口**：分析 › 自定义报表（所有角色可用）。
- **构建器**：
  - 对象：线索、客户、商机、跟进。
  - 明细报表：选择最多 15 列、排序（文本、下拉、数字、金额、日期、是否）、分页（每页最多 100 条）。
  - 汇总报表：按下拉字段、负责人、是否、关联客户、区域或日期（按月、季度、年，UTC）分组；指标为记录数，以及数字、金额字段的合计、平均、最小、最大（最多 3 个）；可选条形图或柱状图。
  - 筛选（全部满足，最多 10 个）：文本包含/等于/为空/不为空；下拉等于/不等于（含空值）/为空/不为空；数字与金额等于/大于等于/小于等于；日期起止、最近 N 天、本月、今年、为空；负责人等于（含“我自己”）/为空；是否；关联客户、区域等于/为空。
  - 金额指标只在单一币种下计算：须按币种分组，或筛选“币种等于”。
  - 可先预览再保存。
- **取数范围**：运行时按查看者的可见范围（与列表一致：负责人范围，客户与商机含区域只读范围）。共享报表也按查看者的范围运行，不会越权。
- **下拉字段**：使用组织配置的选项与名称（#65），自定义选项可用于筛选与分组，导出显示组织的名称。
- **维护与权限**：私有报表所有用户可建；共享给全组织需 view.share（管理员、经理）；只有创建者能修改，对象不可改；共享报表也可由 view.share 持有者删除；每人最多 50 个；新建、修改、删除、导出写审计。
- **导出**：CSV 与 Excel（需导出权限）。明细导出全部行（最多 10000 行），汇总导出各组与合计。
- **上限**：汇总最多统计 20000 条记录，超出时提示只统计了前 20000 条。
- **演示数据**：郑经理共享的“【演示】各阶段商机金额（美元）”“【演示】线索来源分布”，王芳的私有“【演示】我的谈判中商机”。
- **不做**：多级分组、跨对象（关联）报表、计算字段、定时发送、仪表盘组件、联系人与工单等其他对象。

## 第一轮：功能测试
命令：`npx vitest run tests/custom-reports/custom-reports.r1-functional.test.ts`
结果：**5/5 通过**（首次运行有测试问题，见下方“失败与修复”）。原始输出：[results/custom-reports-r1-functional.txt](results/custom-reports-r1-functional.txt)

覆盖：
- **字段目录与校验**：四个对象的字段；17 类非法定义（无列、未知列、重复列、运算不适用、下拉值格式、无效日期、无值运算带值、负责人值、文本分组、日期分组缺粒度、非日期带粒度、无分组的指标、无分组的图表、金额缺单一币种、非数字指标、按关联字段排序、未知对象）。
- **明细**：列、按金额降序、分页、金额与币种、关联客户与负责人名称；文本包含/等于、为空/不为空、下拉不等于、最近 N 天、日期上限、负责人为“我自己”；是否、关联客户筛选。
- **汇总**：按阶段（合计、平均、最大）、按币种、按负责人（显示姓名）、按月与按季度、空值分组；销售只统计自己负责的。
- **维护**：私有与共享、同名、没有 view.share 不能共享、列表只含自己的与共享的、他人私有报表 404、共享报表按查看者范围运行、只有创建者能改、对象不可改、删除权限、审计。
- **导出**：CSV 表头与金额、汇总的各组与合计、Excel；没有导出权限 403，有权限也看不到他人的私有报表（404）；导出写审计。

## 第二轮：集成测试
命令：`npx vitest run tests/custom-reports tests/reports tests/report-exports tests/report-excel tests/picklists tests/territory-visibility tests/views tests/audit tests/rbac tests/i18n tests/demo`
结果：**24 个文件 212/212 通过**（本功能第二轮首次运行 4/5，见下方）。原始输出：[results/custom-reports-r2-integration.txt](results/custom-reports-r2-integration.txt)

覆盖：
- **演示报表**：三个报表名称带【演示】、定义合法；只读用户只看到两个共享报表，王芳看到三个；美元阶段报表的数量与金额与数据库直接统计一致；王芳运行同一报表的数量与她的商机列表一致（含所在区域），看不到郑经理的人民币商机；私有报表对他人 404。
- **区域只读范围与组织隔离**：区域代表在报表中看到区域内他人的商机，按区域分组显示区域名称；其他组织读不到、运行不了报表，用本组织客户 ID 筛选得不到数据。
- **并发与约束**：同一用户同时新建 55 个只成功 50 个；5 类不合法的数据库写入（空名称、图表无分组、未知图表、列不是数组、重名）与跨组织负责人均被拒绝。
- **上限**：20005 条线索时汇总只统计 20000 条并标记截断；明细总数仍准确。
- **自定义下拉选项与 API 密钥**：按自定义来源筛选；导出显示改名后的名称与自定义选项名称；以销售身份的密钥看不到管理员的私有报表，新建的报表属于该销售。

### 失败与修复
| 现象 | 原因 | 修复 |
|---|---|---|
| 迁移首次执行失败（本地两库） | 操作问题：修改 schema 的脚本因锚点文本不匹配中止，迁移只含手写约束 | 在本地两库标记回滚、删除并重新生成（见上方“迁移”）；生产库未受影响 |
| R1 首次：中文排序预期顺序不符 | 测试问题：按编码排序时“甲”在“乙”“丙”之后 | 改正预期 |
| R1 首次：按负责人分组顺序不符 | 测试问题：数量相同时顺序不固定 | 改为排序后比较 |
| R1 首次：导出表头为“商机金额” | 测试问题：预期写成了“金额” | 改正预期 |
| R1：销售导出他人报表返回 403 而非 404 | 测试预期不准确：销售没有导出权限，先返回 403 | 改为用有导出权限的经理验证 404，并补充销售 403 |
| R2 首次：王芳的统计数量不小于全部 | 测试假设错误：王芳是“海外”区域成员，所有美元商机都在她的区域内 | 改为与她的商机列表核对，并验证看不到郑经理的人民币商机 |
| E2E 首次：金额显示不是“US$” | 测试问题：金额格式为“USD 1,234.00” | 改正预期 |
