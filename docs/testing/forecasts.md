# 销售目标与预测 — 三轮测试记录

日期：2026-11-13　环境：同 [leads.md](leads.md)　参考：Zoho CRM Forecasts
迁移：`20261113171607_sales_targets`（sales_targets 表；组织 × 负责人 × 月份 × 币种唯一；负责人与修改人复合外键保证同组织；金额非负、月份为当月 1 日、币种为 3 位大写字母的 CHECK）

## 功能
- 左侧导航新增“销售预测”：按月或季度、币种查看每位负责人一行及团队合计。
- 指标：目标、已赢单（单数）、完成率、距离目标（超出时显示“超出 …”）、在手商机（单数）、加权预测、预测、预测完成率、最好情况；顶部指标卡为团队合计。
- 口径（与报表一致）：赢单与在手商机按“预计成交日期”落在期间内；加权预测 = 进行中商机金额 × 阶段赢单概率（资格确认 10%、需求分析 20%、方案报价 40%、商务谈判 70%）；预测 = 已赢单 + 加权预测；最好情况 = 已赢单 + 全部在手商机；金额按币种，不做汇率换算。
- 目标：管理员与经理（新权限 `forecast.manage`）在月视图表格中直接填写（回车或失焦保存，清空即清除）；季度目标为三个月之和，只读；目标变更写审计 `target.update`（前后金额）。
- 参与统计的用户：未停用的非只读用户（即使本期没有数据）、本期有目标或商机的用户（含已停用）；未分配负责人的商机单列（无目标）。
- 可见范围：销售代表只看到自己一行（合计即自己）；经理、管理员、只读看到全部；只读不能修改。
- 中英文文案同时提供；审计日志页筛选新增“销售目标”，并补上此前遗漏的“视图”“附件”对象类型；审计详情显示目标所属负责人、月份与币种。
- 演示数据：经理（人民币）与两位销售代表（美元）从 5 个月前到 2 个月后的月度目标，共 24 条。
- 不做：自定义阶段概率、按季度/年直接设定目标、按团队或部门汇总。

### 失败与修复
| 现象 | 原因 | 修复 |
|---|---|---|
| 生成迁移时 Prisma 只输出版本号 | 操作失误：按文本锚点插入 User/Organization 反向关联时，锚点因列对齐变化未匹配，插入静默失败，schema 校验不通过 | 用 `prisma validate` 定位，按不受空格影响的方式重新插入后生成迁移 |
| 类型检查报 salesTarget 不存在 | Prisma 7 的 migrate dev 不再自动生成客户端 | 执行 `prisma generate` |
| 开发阶段 E2E：合计行没有“预测”金额 | **界面遗漏**：表格只有加权预测与预测完成率，缺少“预测”金额列 | 表格与合计行补充“预测”列，E2E 增加断言 |
