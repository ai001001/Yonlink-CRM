# 列表导出 Excel — 三轮测试记录

日期：2026-11-19　环境：同 [leads.md](leads.md)　参考：Zoho CRM 列表导出（XLSX）
无数据库迁移。复用 [报表导出 Excel](report-excel.md) 中的写入器 `src/server/xlsx.ts`。

## 功能
- **6 个列表可以下载 Excel**：线索、客户、联系人、商机、跟进、服务工单。
  - 列表页“导出”按钮旁新增“下载 Excel”按钮，按当前筛选导出。
  - 列、筛选、排序、可见范围、10,000 行上限及截断标记都与 CSV 相同。
- **Excel 的特点**：
  - 工作表名为列表名称，随语言变化（如“线索”“Leads”）。
  - 表头加粗并冻结。
  - 商机金额是金额格式的数字单元格；客户的联系人数、工单的处理记录数是整数单元格。
  - 文本一律为内联字符串，以 `=` 开头的内容不会被当作公式（CSV 仍按原来的方式加单引号前缀）。
- **CSV 不变**：导出代码重构为同一套“表头 + 行”，CSV 渲染结果与改动前完全一致（原有的 CSV 精确断言全部通过）。
- **接口**：6 个导出接口支持 `format=xlsx`；不传为 CSV；其他取值返回 400。
- **权限与审计**：需要导出权限（管理员、经理）；Excel 导出的审计筛选条件中记录 `format: 'xlsx'`，CSV 不记。

## 第一轮：功能测试
命令：`npx vitest run tests/list-excel/list-excel.r1-functional.test.ts`
结果：**2/2 通过（第四次运行通过，前几次失败见下表）**。原始输出：[results/list-excel-r1-functional.txt](results/list-excel-r1-functional.txt)

覆盖：
- **6 个列表逐个核对**：
  - 响应类型、文件名、导出条数与 CSV 相同；工作表名正确，冻结表头。
  - 表头与 CSV 相同且加粗；行数与 CSV 相同。
  - 逐个单元格与 CSV 相同：空值对应空单元格；数字列为数字单元格且样式正确；CSV 中防公式注入的单引号前缀在 Excel 中不需要。
  - 英文工作表名正确。
- **公式样文本**：以 `=` 开头的线索名在 Excel 中仍是文本，没有公式。
- **筛选**：按线索状态、商机阶段筛选后，Excel 只含筛选结果；商机金额 12345.6 为数字。
- **审计**：Excel 导出记录格式和筛选，CSV 不记格式。
- **校验与权限**：`format=docx` 返回 400；销售代表、只读用户导出 6 个列表的 Excel 都返回 403。
