说明：自定义字段原列在路线图“暂不做”中；负责人要求按 Zoho CRM 补齐功能，本功能起移出该列表。

迁移 `20261130090000_custom_fields`：
- 枚举 `custom_entity`（线索、客户、联系人、商机）与 `custom_field_type`（单行文本、多行文本、数字、日期、下拉单选、勾选、网址、邮箱）。
- 新表 `custom_fields`（对象、键、名称、类型、选项、必填、启用、顺序）；约束：键为 `cf_` + 8 位小写字母数字、名称非空白且同一对象内不重复（不分大小写）、选项为数组且最多 50 个、只有下拉有选项、顺序非负。
- `leads`、`accounts`、`contacts`、`deals` 新增 `custom` JSON 列（默认空对象，必须是对象）。
- 应用迁移后，`prisma migrate diff` 与数据库对比为空迁移，没有漂移。

## 功能
- **定义**（设置 › 自定义字段，`customfield.manage`：仅管理员）：按对象新建字段（键由服务端生成、不可改），可改名称、下拉选项、必填、启停；类型与对象不可改；勾选不能设必填；每个对象最多 30 个（加锁判断）；删除字段时清除所有记录中该字段的值。所有用户可读取定义（表单需要）。写审计。
- **取值**：随记录的新建、编辑提交 `custom: { 字段键: 值 }`。
  - 只接受启用字段；按类型校验并规范化：文本去首尾空格（≤255/5000）、数字最多 16 位整数 4 位小数（按字符串保存，去掉多余的 0）、日期必须是有效的 YYYY-MM-DD、下拉必须是选项之一、勾选为布尔、网址须 http/https、邮箱转小写。
  - 值为 null 或空字符串表示清除；编辑只改提交的键；不提交 custom 的编辑（批量、看板等）不动值。
  - 必填：新建时、以及编辑提交了 custom 时检查（因此新增必填字段后，批量修改旧记录不会被拦，在表单中编辑时要求补齐）。
  - 停用字段：不显示、不能填写，已有值保留。
- **界面**：线索、客户、联系人（联系人页与客户详情中的联系人面板）、商机的新建/编辑表单按类型显示输入项（下拉、日期选择、开关、数字等），服务端的字段错误显示在对应输入项下；详情中显示“自定义字段”一节。
- **导出**：线索、客户、联系人、商机的 CSV 与 Excel 导出在最后追加启用字段的列（勾选显示“是/否”）。
- **导入**：线索、客户导入时，表头与启用字段名称相同的列作为该字段导入，按同样规则校验（勾选接受 是/否、yes/no、true/false、1/0），必填字段缺值报错。
- **审计**：记录的新建与修改审计中按字段名称记录自定义值的变化；文本、多行文本、网址、邮箱的值脱敏。
- **回收站**：删除后恢复，自定义值随记录恢复。
- **演示数据**：线索“意向产品线”（下拉）、客户“年采购预算（万元）”（数字）与“是否经销商”（勾选）、联系人“微信号”（文本）、商机“交付方式”（下拉），并为全部演示记录填好值。
- **不做**：列表中的自定义字段列、按自定义字段筛选与排序、在工作流/验证规则/评分中使用自定义字段、线索转化时把线索字段映射到客户/商机、字段排序拖拽。

## 第一轮：功能测试
命令：`npx vitest run tests/custom-fields/custom-fields.r1-functional.test.ts`
结果：**5/5 通过（首次即通过）**。原始输出：[results/custom-fields-r1-functional.txt](results/custom-fields-r1-functional.txt)

覆盖：
- 定义：新建（键格式、顺序）；同名 409、不同对象可同名；8 类非法定义 400（空名称、未知类型、下拉无选项、文本带选项、选项大小写重复、勾选必填、未知对象、指定键）；经理 403、可读取；改名称/选项/必填；类型不可改、下拉选项不能清空、勾选不能必填也不能有选项；删除时清除 2 条记录的值、其他字段的值保留；审计序列；每个对象 30 个上限（其他对象不受影响）。
- 取值：8 种类型的规范化结果；10 类非法值（科学计数法、5 位小数、2 月 30 日、不在选项内、勾选用字符串、javascript: 网址、邮箱缺域名、文本超长、文本给数字、未知字段）分别返回对应代码；custom 不是对象 400；停用字段不能写入、值保留；编辑只改提交的键、null 清除；不提交 custom 的编辑不动值；新建与修改审计按名称记录、文本类脱敏。
- 必填：新建缺值 400；批量改状态不受影响；表单编辑提交 custom 时必须补齐；客户（数字规范化、非法值 400）、联系人（新建、清除）、商机（下拉非法 400）都可用；其他对象的键不能用。
- 导出：CSV 末尾追加“等级、重点”两列，值为“A、是”；停用字段不导出。导入：同名列导入、勾选“是”、非法选项与必填缺值逐行报错，有效行写入正确的值。
