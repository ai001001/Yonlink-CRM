# 发票 — 三轮测试记录

日期：2026-11-14　环境：同 [leads.md](leads.md)　参考：Zoho CRM Invoices
迁移：`20261114150000_invoices`（新表 `invoices`、`invoice_line_items`、`invoice_payments`，枚举 `invoice_status`、`payment_method`；部分唯一索引：同一订单只能有一张未作废的发票；CHECK：总计 = 小计 + 税额、0 ≤ 已收 ≤ 总计、状态与已收金额一致、付清 / 作废时间与状态一致、到期日不早于开票日期、收款金额大于 0；发票对订单、商机的外键为 RESTRICT）

## 功能
- 生成：销售订单详情中，未取消且没有未作废发票的订单显示“生成发票”。
  - 主题默认为订单主题，开票地址默认为订单收货地址；开票日期默认今天，到期日默认 30 天后；到期日不能早于开票日期。
  - 明细、币种、税率与金额复制自订单，生成后不再变化；发票号按组织、按年连续编号（INV-2026-0001）。
  - 生成时锁定订单行，与取消订单互斥：不会出现“订单已取消但发票有效”。
- 收款：登记金额、收款日期、方式（银行转账 / 现金 / 支票 / 刷卡 / 其他）、凭证号；金额默认为未付余额。
  - 状态随已收金额自动变化：未付款 → 部分付款 → 已付清；收款超过未付余额时拒绝。
  - 登记与撤销都用一条条件更新同时修改金额与状态，并发收款不会超收。
  - 登记错的收款可以撤销，状态随之回退。
- 作废：只有没有收款的发票能作废（可填原因）；作废后不能修改或收款，订单可以重新开票。
- 逾期：未付清且到期日早于今天（按 UTC 日期）时显示“逾期”，列表可按逾期筛选。
- 订单有未作废发票时不能取消，提示先作废发票；发票不能删除。
- 页面：
  - 左侧导航“发票”：按状态与逾期筛选，按发票号、主题、订单号、商机、客户搜索；列表显示未付余额。
  - 发票详情抽屉（收款记录、登记 / 撤销收款、作废、修改）；打印页 `/print/invoice?id=…`。
  - 订单详情列出由它生成的发票。
- 权限：可见与编辑跟随所属商机（销售代表只能操作自己负责商机的发票，只读用户只能查看）。
- 审计：生成、修改、登记收款、撤销收款、作废（`invoice.create / update / payment / payment_delete / void`），收款审计记录金额、方式与前后的已收金额和状态；开票地址、备注、作废原因脱敏；审计日志可按“发票”筛选。
- 中英文文案；演示数据：为已发货、已交付的订单各开一张，共 5 张（一次付清、分两次付清、部分付款且逾期、未付款且逾期、未付款未到期）。
- 不做：一张订单分多次开票、红字发票 / 退款、电子发票与税控对接、在线支付、多币种换算。
