## 功能
- **设置 › 下拉选项**（需 customfield.manage，即管理员）：
  - 线索来源、行业：可新增自定义选项（代码由服务端生成）、改名、上下移动、停用；内置选项不能删除；自定义选项未被记录使用时可删除，使用中只能停用。
  - 线索状态、商机阶段、跟进类型：只能改名与停用，顺序固定、不能新增；线索“新建”“已转化”与商机“赢单”“输单”不能停用。
  - 进行中的商机阶段可设置赢单概率，销售预测的加权金额、阶段历史的可能性与预期收入随之变化。
  - 名称留空时使用系统默认名称（随语言切换），填写后所有语言都显示该名称。每次保存整组替换并写审计，同一字段的保存串行执行。
- **生效范围**：
  - 显示：列表、详情、看板、筛选、报表、审计、工作台等所有界面，以及 CSV/Excel 导出与报表导出，都显示组织的名称。
  - 选择：新建、编辑、批量修改、转化线索、网页表单只列启用的选项（编辑时保留记录当前的值）；筛选与规则编辑（工作流、验证规则、区域、评分、分配、宏、销售节奏）列出全部选项（含已停用）。
  - 服务端检查：线索、客户、商机、跟进的新建与编辑，转化线索时的商机阶段，网页表单的来源，导入，都只接受启用的选项（未改变的旧值可保留）；新建商机未指定阶段时用第一个启用的进行中阶段。规则引用的线索来源、行业须是本组织配置中的选项（已停用的也可引用）。
  - 导入时识别自定义名称与改名后的名称；不存在的选项报“值不正确”，停用的选项报“该选项已停用”。
  - 并发：写入使用自定义选项的记录时与删除该选项互斥（事务内加锁并复核），不会出现引用已删除选项的记录。
- **不按选项检查的系统写入**：流程蓝图转换（按管理员配置的转换执行）、工作流动作、销售节奏生成的跟进、网页表单提交（使用表单保存时的来源）。
- **演示数据**：新增自定义线索来源“【演示】短视频平台”与行业“【演示】新能源汽车”；不改名、不改概率，其他演示数据与报表口径不变。
- **不做**：其他下拉字段（工单优先级、报价状态等）、多条销售管道、按角色或布局区分选项、选项之间的联动。

覆盖：

- **固定字段**：阶段改名、停用、改概率，未填概率用默认；不能调整顺序、新增、停用赢单、给输单设概率、概率超过 100；线索“新建”不能停用；状态改名；类型停用。

- **概率**：销售预测加权金额与阶段历史随配置的概率变化。

### 失败与修复
| 现象 | 原因 | 修复 |
|---|---|---|
| R1 首次：工作流用例 400 | 测试问题：触发时机写成了 `CREATED`（应为 `CREATE`），通知动作写成了 `NOTIFY_OWNER` | 改正请求 |
| 现有测试：评分规则保存返回 500 | 产品问题：数据库约束把评分规则中的来源、行业限定为内置值，自定义选项会违反约束 | 新迁移把这两个字段改为只检查代码格式 |
| 现有测试：分配、区域规则接受了不存在的值 | 产品问题：放宽为“代码格式正确即可”后失去了存在性检查 | 规则保存时检查是否为本组织的选项（含已停用），覆盖评分、分配、区域、工作流、验证规则、宏 |
| 现有测试：导入中不存在的来源原因变为“格式不正确” | 产品问题：原因代码与原有约定不一致 | 不存在的选项仍报“值不正确”，新增“该选项已停用” |
| R1：评分为 0 | 测试问题：同一用例中前面建的工作流把来源改回了“官网” | 调整工作流条件，同时覆盖“动作设为自定义选项” |
| R2 首次：删除自定义选项的同时新建线索，线索引用了已删除的选项 | 产品问题（并发）：写记录时的选项检查在事务之外 | 写入自定义选项时在事务内加共享锁并复核，删除选项持有同一键的排他锁 |
| R2 首次：报表导出 400 | 测试问题：时间段超过 24 个月上限 | 改为本年至今 |
| E2E：新选项输入框找不到 | 产品问题：新选项的无障碍名称使用了内部键 | 改为“显示名称 新选项名称” |
| E2E：找不到“陌生拜访” | 测试问题：内置名称是“电话开发” | 改正 |
