# 线索转化（Lead Conversion）— 三轮测试记录

日期：2026-11-10　环境：同 [leads.md](leads.md)

## 功能说明
`POST /api/leads/:id/convert`：在一个事务内
1. 新建客户（默认名称取公司名，无公司取姓名，可自定义）或关联本组织已有客户；
2. 用线索的姓名、职位、手机（无则电话）、邮箱创建联系人；新客户或客户无主要联系人时设为主要联系人；
3. 可选创建商机（名称、金额、币种、阶段、预计成交日期）；
4. 线索的跟进记录补充关联到该客户与商机（不覆盖已有关联，保留线索关联）；
5. 线索标记“已转化”，记录转化时间与客户/联系人/商机链接。
转化不可逆；“已转化”只能通过此接口设置；已转化线索的状态不可修改（其他字段可编辑）。负责人沿用线索负责人（无则当前用户）。

### 失败与修复
| 现象 | 原因 | 修复 |
|---|---|---|
| 删除转化出的客户失败，线索链接未置空（`convertedAccountId` 仍有值） | 删除客户时外键 SET NULL 与联系人级联删除在同一语句中发生；同组织触发器在这次更新中又校验了未改动且已被级联删除的联系人链接而抛错，整个删除回滚 | 新迁移 `lead_conversion_trigger_fix`：触发器只校验本次实际改动且非空的列；测试补充删除接口返回 204 的断言 |
| 跨组织链接用例期望错误信息含 “another organization”，实际为 “Foreign key constraint violated” | 触发器使用外键错误码 23503，Prisma 统一报告为外键错误（拦截本身生效） | 调整断言，并补充“数据未被修改”和“同组织链接允许”两项检查 |
