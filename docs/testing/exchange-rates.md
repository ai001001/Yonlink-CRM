# 汇率与本币汇总 — 三轮测试记录

日期：2026-11-15　环境：同 [leads.md](leads.md)　参考：Zoho CRM Multi-Currency
迁移：`20261115090000_exchange_rates`（新表 `exchange_rates`；`invoices` 新增 `exchange_rate`、`base_total`；CHECK：汇率为正、本币不录汇率、币种为三位大写字母、发票快照与折合金额同时有或同时为空）

## 功能
- 本币为人民币（CNY）。左侧导航新增“汇率”：显示各外币（USD、EUR、HKD、JPY）今天的有效汇率与汇率历史。
- 汇率含义为“1 单位外币 = 多少人民币”，按生效日期保存；查询某日汇率取该日及之前最近生效的一条；本币恒为 1。
- 管理员（新权限 `rate.manage`）可录入汇率（同币种同生效日期再次录入即修改）或删除录错的汇率；其他角色只能查看。录入、修改、删除写审计（审计对象“汇率”）。
- 发票汇率快照：生成发票时按开票日期取汇率，记录汇率与折合人民币金额；人民币发票为 1；开票日没有该币种汇率时为空并显示“无汇率”；修改开票日期时按新日期重取；之后的汇率变更不影响已开发票。
- 报表本币汇总（按今天的汇率）：
  - 销售报表：全部币种折合人民币的在手商机金额与期间赢单金额。
  - 应收账款：全部币种折合人民币的未收与逾期金额。
  - 缺少汇率的币种不计入，并在提示中列出。汇总遵循可见范围（销售代表只含自己的数据）。
- 金额折算使用十进制计算，四舍五入到分。
- 演示数据：每种外币两期汇率（200 天前、30 天前生效，数值为演示用近似值）；演示发票均带开票日快照。
- 不做：切换本币、自动获取汇率、汇兑损益、报价单与订单的汇率快照、报表整体切换为本币显示。

### 失败与修复
| 现象 | 原因 | 修复 |
|---|---|---|
| 演示发票折合金额初版用普通浮点数计算（开发中自查） | 浮点乘法可能产生分位误差 | 改用与服务端相同的十进制折算函数 `toBase`，重建后核对 5 张演示发票的快照 |
| E2E 首次 1 项失败：退出登录时找不到用户菜单 | 测试代码未关闭发票详情抽屉，遮罩挡住了右上角菜单（汇率快照断言此前已通过） | 先用 `closeDrawer` 关闭抽屉；切换币种改用带重试的 `selectOption` |
