# 产品库存 — 三轮测试记录

日期：2026-11-25　环境：同 [leads.md](leads.md)　参考：Zoho CRM（Inventory）产品的库存数量（Qty in Stock）与再订货水平（Reorder Level）

迁移 `20261125090000_stock`：
- `products` 新增 `stock_quantity`（默认 0）与 `reorder_level`（可空，非负）。
- 新表 `stock_movements`（原因：手工调整、采购收货、销售发货、取消退回；带符号数量、变动后余额、来源采购单/销售订单、备注、操作人）。
  - 产品为复合外键（同组织），有流水的产品不能删除（RESTRICT）；来源单据删除时置空、流水保留，同组织由触发器保证。
  - 约束：数量非 0、备注非空白。
- 触发器：
  - `stock_movements_apply`（写入前）：校验来源单据同组织，原子更新产品库存（产品行锁使并发流水依次累加），写入变动后余额。
  - `stock_movements_no_update`：流水只增不改（来源单据删除时置空除外）。
  - `products_stock_guard`：产品库存只能由流水改变，直接修改被拒绝。
- 应用迁移后，`prisma migrate diff` 与数据库对比为空迁移，没有漂移。

## 功能
- **库存来源**（全部通过流水）：
  - 手工调整：增减数量或盘点为指定数量（行锁内算差额；无变化 409），必须填写原因，需 `product.manage`（管理员、经理），写审计。
  - 采购收货：按收货数量增加（每次部分收货各一条，采购单收货审计附带库存变动）。
  - 销售订单发货：按订单明细数量减少；送达不变；已发货订单取消时按原发货数量退回（只退一次）；未发货取消不影响库存。
  - 单据明细按 SKU 对应产品（含已停用）；没有对应产品的手工明细不影响库存。
  - 允许库存为负（发货不被库存阻挡），界面红色显示。
- **再订货水平**：产品编辑中设置；库存不高于它为“低库存”。
- **界面**（库存 › 产品）：
  - 列表新增“库存”（数量 + 单位，缺货红色标签、低库存橙色标签）与“再订货水平”列。
  - 库存筛选：全部 / 低库存（数量）/ 缺货（数量，≤ 0），数量只统计启用产品。
  - 每行“库存”按钮打开库存抽屉：当前库存、再订货水平、手工调整（有权限时）、库存流水（时间、类型、变动、变动后库存、来源单据链接或原因、操作人，分页）。
- **权限**：所有用户可查看库存与流水；采购单号只对有 `purchase.read` 的用户显示。有库存流水的产品不能删除，只能停用。
- **演示数据**：每个演示产品按“期初库存 → 采购收货 → 销售发货”的时间顺序写入流水（期初 = 目标库存 + 发货 − 收货，且不少于发货量，过程中不为负）；一半产品设置再订货水平；1 个低库存、1 个缺货示例。
- **不做**：多仓库、批次与序列号、库存预留（下单即占用）、低库存通知。
