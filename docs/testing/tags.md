# 标签 — 三轮测试记录

日期：2026-11-12　环境：同 [leads.md](leads.md)　参考：Zoho CRM Tags
迁移：`20261112162624_tags`（tags 表；lead_tags / account_tags / deal_tags 关联表，复合外键保证同组织，记录或标签删除时关联级联删除；name_key 组织内唯一且必须等于小写去空格的名称、名称非空、颜色属于预设色板的 CHECK）

## 功能
- 线索、客户、商机可打多个彩色标签：列表新增“标签”列与“按标签筛选”；详情中“+ 标签”选择已有标签或输入名称直接新建，标签上的 × 移除。
- 批量操作栏新增“添加标签 / 移除标签”（逐条按记录编辑权限，已有的不重复）。
- 标签管理（筛选框旁齿轮按钮）：新建、改名、改色、删除（删除时提示将从多少条记录移除）。
- 权限：能编辑记录的用户可新建标签和给自己可编辑的记录打标签；改名、改色、删除需新权限 `tag.manage`（管理员、销售经理）；只读用户只能查看。
- 规则：标签名组织内唯一（不区分大小写），1–30 字、不能含 `, < >`；每条记录最多 20 个标签，每个组织最多 200 个。
- 审计：tag.create / update / delete（删除时记录移除的关联数量），lead/account/deal.tags（记录新增与移除的标签名）；审计日志页筛选新增“标签”与“修改标签”。
- 接口：`GET/POST /api/tags`、`PATCH/DELETE /api/tags/:id`、`PUT /api/{leads|accounts|deals}/:id/tags`、列表 `tagId` 参数、批量 `tag_add` / `tag_remove`。
- 演示数据：6 个标签（重点客户、战略合作、年度框架、价格敏感、展会线索、需要样品），按数据确定性分配到客户、商机、线索。
- 不做：标签不进入 CSV 导入导出；跟进与报价单暂不支持标签。

### 失败与修复
| 现象 | 原因 | 修复 |
|---|---|---|
| 开发自查：演示网站上设置标签会被浏览器拦截 | **真实缺陷（上线后才会出现）**：跨域响应头 `Access-Control-Allow-Methods` 不含 PUT，而演示前端（GitHub Pages）与后端不同域 | 加入 PUT；R2 新增跨域预检测试 |
| 开发阶段 E2E：批量“添加标签”下拉里没有刚新建的标签 | **真实缺陷**：批量操作栏只在页面加载时取一次标签 | 每次展开下拉时重新加载 |
| 开发阶段 E2E：“管理标签”弹窗显示“暂无标签” | **真实缺陷**：弹窗在页面加载时取标签，之后新建的看不到、使用次数不更新 | 每次打开弹窗时重新加载 |
| 开发阶段 E2E：两处断言失败 | 测试脚本：客户名本身含 “E2E”；审计页同时存在已关闭弹窗中的表格 | 删除错误断言；限定为可见表格 |
