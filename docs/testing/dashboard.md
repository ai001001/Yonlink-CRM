### E2E 过程中的问题
| 现象 | 原因 | 处理 |
|---|---|---|
| 各模块 E2E 中 `getByRole('link', { name: '客户' })` 命中 2 个元素 | 工作台成为首页后，KPI 卡片也是“客户数量”链接 | 新增 `nav()` 辅助函数，只在左侧菜单中精确匹配 |
| 商机详情抽屉打开时，向顶部搜索框回车无效 | 抽屉打开时焦点锁定在抽屉内（真实用户也无法穿过遮罩点击搜索框），属于测试步骤不符合实际操作 | 测试先关闭抽屉再搜索 |
| 全量运行时商机 E2E 金额合计断言失败（单独运行通过） | 工作台 E2E 留下的商机计入合计，用例之间存在数据依赖 | 断言前先按商机名称筛选，合计只统计本用例数据 |
