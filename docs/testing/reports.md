# 报表与图表（销售报表）— 三轮测试记录

日期：2026-11-12　环境：同 [leads.md](leads.md)　参考：Zoho CRM Reports / Dashboards（销售漏斗、按月赢单、负责人业绩、线索来源）
迁移：无（只读统计，不改表结构）

## 功能
- 左侧导航新增“报表”，接口 `GET /api/reports/sales?currency=&from=&to=&ownerId=`。
- 筛选：币种（按币种分别统计，不做汇率换算）、时间段（默认最近 12 个月，含本月/本季度/今年/最近 12 个月预设，最长 24 个月）、负责人（经理、管理员、只读用户可选）。
- 指标卡：进行中商机金额与数量、期间赢单金额（赢单/输单数）、赢单率、线索转化率、报价接受率。
- 图表与表格：销售漏斗（进行中商机按阶段）、按月赢单金额（并标出输单数）、负责人排行（在手、赢单、输单、赢单率、跟进数）、线索来源转化、报价单状态数量与金额。
- 统计口径（页面同时说明）：漏斗为当前进行中商机（不受时间段影响）；赢单/输单按“预计成交日期”落在时间段内统计；线索、报价单、跟进按创建时间统计（UTC，含开始日与结束日）；赢单率 = 赢单 ÷ (赢单 + 输单)；报价接受率 = 已接受 ÷ (已接受 + 已拒绝)；分母为 0 时显示“—”。
- 权限：遵循可见范围，销售代表只统计自己负责的数据（指定他人为负责人时结果为空，不泄露）；按组织隔离。
- 图表为轻量自绘组件（横向条形 HTML、纵向柱状 SVG），不引入第三方图表库。
- 演示数据调整：已结束商机的预计成交日期分布在过去约 11 个月（商机创建时间、报价单时间相应早于成交日期）；为赢单与谈判中商机追加 16 条“已转化”来源线索（关联客户与商机），线索共 64 条。

### 失败与修复
| 现象 | 原因 | 修复 |
|---|---|---|
| R1：线索来源测试写入测试数据失败 | 测试数据问题：已转化线索必须带转化时间（数据库 CHECK `leads_converted_consistent`），测试构造器未设置 | 构造器为已转化线索设置转化时间 |
| 本地预览：漏斗图文字在窄列中缩得很小 | SVG 按宽度等比缩放，文字随之变小 | 横向条形图改为 HTML 布局，文字保持正常字号 |
| 本地预览：按月图表只有最近 3 个月有数据、线索转化率为 0% | 演示数据：已结束商机成交日期只在过去 90 天内，且没有已转化线索 | 调整演示数据（见上），不改变既有样本 |
| R3 首次：线索 E2E 新建线索后“来源”为空（[首次失败输出](results/reports-r3-regression-first-run-failed.txt)） | 测试脚本时序问题：操作轨迹显示点击了“展会”选项但未生效——antd 下拉展开动画期间的点击可能被忽略（与本次改动无关，此前各轮均通过） | 线索与审计 E2E 改用已有的 `selectOption`（选择后校验、未生效自动重试）。曾尝试把其他 4 个用例也一并替换，但该辅助函数在这些弹窗中不适用（4 个失败），已撤回，只保留验证通过的两处；完整重跑 R3 |
