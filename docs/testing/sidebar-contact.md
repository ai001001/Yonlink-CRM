# 侧栏折叠与咨询方式 — 三轮测试记录

日期：2026-11-17　环境：同 [leads.md](leads.md)　参考：https://ai001001.github.io/Yonlink-ERP/ 的侧栏与咨询方式　依赖：[导航结构](navigation.md)
迁移：无

## 功能
- **分组可折叠**：销售、营销、活动、库存、服务、分析、设置改为可以折叠的分组，点击分组标题可以单独展开或收起。工作台不在任何分组里，始终可见。
- **侧栏顶部按钮**（与 ERP 一致）：
  - “« 收起侧栏”：侧栏缩成只显示图标的窄条（64px），把鼠标移到分组图标上会弹出该组菜单。收起后，侧栏顶部和页面顶部栏的按钮都可以重新展开。
  - “全部收起”：收起所有分组，只保留当前页面所在的分组。
  - “全部展开”：展开所有分组。
- **顶部栏**：新增 ☰ 按钮，用于切换侧栏收起或展开。
- **状态保存**：收起状态和展开了哪些分组，保存在本浏览器的 localStorage，刷新后保持；不跨浏览器或设备同步；存储不可用时使用默认值，即全部展开。
- **自动处理**：
  - 打开某个页面时，自动展开它所在的分组。
  - 窄屏（小于 992px）时自动收起侧栏；回到宽屏时恢复用户自己的选择。
- **侧栏布局**：侧栏固定为整屏高度，菜单区域可以单独滚动，咨询方式固定在侧栏底部。
- **咨询方式**（内容与 ERP 一致：QQ 3313395633，学无止境）：
  - 侧栏底部：显示“咨询方式 / QQ：3313395633 / 学无止境”，以及“复制QQ号”按钮；侧栏收起时显示为一个图标，鼠标移上去显示 QQ，点击即复制。
  - 顶部栏：“咨询QQ：3313395633（学无止境）”标签，点击即复制；只在宽屏（≥1200px）显示，避免挤占顶部栏。
  - 登录页：登录按钮下方的咨询卡片，带“复制QQ号”按钮。
  - 复制成功时提示“已复制QQ号 …”；浏览器不支持复制时，改用备用方式，仍失败则提示手动记下号码。
  - QQ 号只在 `src/lib/contact.ts` 中维护，也可以用环境变量 `NEXT_PUBLIC_CONTACT_QQ` 覆盖。称呼放在语言文件中：中文“学无止境”，英文“Xue Wu Zhi Jing”，也可以用 `NEXT_PUBLIC_CONTACT_NAME` 覆盖。
- 不做：拖动调整侧栏宽度、把侧栏状态同步到服务端、在线客服对话窗口。

## 第一轮：功能测试
导航和咨询方式都是界面功能，没有新的服务端逻辑；第一轮做开发中的界面检查：
- 类型检查、lint、生产构建都通过。
- 新增 E2E 用例“侧栏折叠”和“咨询方式”，在开发中运行。

首次运行“侧栏折叠”失败：收起侧栏后刷新页面，侧栏又展开了。**这是功能缺陷**：侧栏组件在页面加载时会根据屏幕宽度触发一次断点回调，原来的实现在宽屏下直接把收起状态设为“展开”，覆盖了刚从本地恢复的“已收起”。

修复：单独记住用户自己的选择，窄屏时自动收起，宽屏时恢复用户的选择。

第一次修复时用 ref 保存这个选择，lint 报错（React 规则不允许在渲染过程中读取 ref），于是改用 state。之后导航 E2E 6/6 通过。
