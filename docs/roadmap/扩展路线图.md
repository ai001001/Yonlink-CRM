# 功能扩展路线图（参考 Zoho CRM）

原则：先重要、后次要；**一次只扩展一个功能**。每个功能完成后执行三轮测试（功能 / 集成 / 回归），全部通过后再推送 GitHub 并发布到演示网站（`scripts/deploy.sh` + GitHub Pages），然后才开始下一个。

|---|---|---|---|
| 1 | 商机销售漏斗看板（拖拽改阶段） | Deals Kanban View | ✅ 已完成（[测试记录](../testing/deal-board.md)） |

| 3 | 数据导入导出（CSV） | Import / Export | ✅ 已完成（[测试记录](../testing/import-export.md)） |
| 4 | 备注（线索/客户/商机） | Notes | ✅ 已完成（[测试记录](../testing/notes.md)） |
| 5 | 产品与报价 | Products / Quotes | ✅ 已完成：第 1 步 产品目录 + 商机产品明细（[测试记录](../testing/products.md)）；第 2 步 报价单（[测试记录](../testing/quotes.md)） |
